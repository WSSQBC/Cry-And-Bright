# Cry-And-Bright
《鸣与明》（Cry &amp; Bright）是一款以回声、共鸣与轮回为主题的中英双语增量游戏。
# 核心玩法

- 调整频率并发声，利用干涉、三度、五度和八度关系改变回响收益。
- 升级基础振动、复音、共鸣、衰减、气息与效率；解锁自动声源和永久声场。
- 每轮按 `V(n+1) = V(n) × 衰减率 × 保留系数` 递推；当递推值 `V(n) ≤ 0.015` 时波链彻底结束，预览和总轮数 n 均按该阈值计算，各轮使用固定间隔。
- 波形以 `V(n)` 作为振荡波的振幅，横向显示当前轮与先前轮次；视口随当前轮滚动，边缘只裁切视图，不参与波链终止判定。
- 不衰减波无法达到阈值时使用 8 层递进软上限，达到安全收益阈值后结束。
- 达成成就与长明重置以获得永久回响点；轮回后解锁新的星图遗物。
- “星海远征 → 星云工坊 → 终响协议”是三个顺序解锁的后期层级。推进要求长明等级与星尘，并重置当轮鸣响、暗寂、声源和普通升级；长明、永久升级、遗物、成就、统计与剧情记录保留。
- 三层门槛依次为长明等级 2/4/6 与 3/8/18 星尘；每层分别提供 1.15×、1.25×、1.4× 全局产出加成，奖励叠乘。
- 航行日志按里程碑逐章解锁，覆盖首次发声、暗寂、长明、远征及终响。界面与剧情均支持简体中文和英语。
- 普通升级新增泛音列（产出加成）与余韵（暗寂加成）；永久升级和星海遗物各增加一个长期成长项。
- 长明点数按本轮获得的暗寂计算，避免同一份历史暗寂在每轮重置时重复兑换；星海档案遗物可提高长明点数收益。

# 存档和本地化

存档保存在浏览器 `localStorage`。首次启动会从旧版 `cry_bright_save_v1` 迁移核心进度到新版存档；已有星尘与遗物等级会保留，新增层级、遗物和升级会为旧存档安全补默认值。设置页可导出或导入 JSON 存档。

界面支持简体中文和英语。新增界面文案时，在 `src/data.js` 的 `STRINGS` 中加入词条。
